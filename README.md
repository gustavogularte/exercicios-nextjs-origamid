# 📖 Sobre

Este repositório reúne todos os exercícios realizados durante o curso **Next.js** da Origamid.

Ao longo do curso foram desenvolvidas aplicações utilizando o framework **Next.js**, explorando conceitos como renderização híbrida, roteamento baseado em arquivos, consumo de APIs, otimização de desempenho e organização de projetos para desenvolvimento de aplicações web modernas.

---

# 🚀 Conteúdos estudados

- ✅ Introdução ao Next.js
- ✅ Estrutura de projetos
- ✅ App Router
- ✅ File-based Routing
- ✅ Layouts
- ✅ Pages
- ✅ Componentes Server e Client
- ✅ Renderização Estática (SSG)
- ✅ Renderização no Servidor (SSR)
- ✅ React Server Components
- ✅ Navegação entre páginas
- ✅ Dynamic Routes
- ✅ Metadata
- ✅ Fetch de dados
- ✅ Consumo de APIs
- ✅ Tratamento de Loading e Error
- ✅ Otimização de imagens
- ✅ Font Optimization
- ✅ Organização de projetos
- ✅ Boas práticas com Next.js
